# VNC MCP

Controls a graphical session over VNC. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/vnc-mcp

Installs from the Camillia hub as `vnc-mcp-30f377`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
